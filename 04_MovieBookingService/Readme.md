# Movie Booking Service

This project is a Movie Booking Service built using Node.js and MySQL. It provides CRUD operations for managing movies, shows, and cinemas. The service is designed to handle the core functionalities of a movie ticket booking system.

## Features

- **Movies**: Add, update, delete, and retrieve movie details.
- **Shows**: Manage show timings, assign movies to shows, and retrieve show details.
- **Cinemas**: Add, update, delete, and retrieve cinema details.
